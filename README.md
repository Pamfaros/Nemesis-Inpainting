# NemesisInpainting

Дослідницький прототип для відновлення кольорових панелей манхви під маскою. На вхід подаються RGB-зображення й маска такого самого розміру. Білий колір позначає ділянку для відновлення. Результат зберігається в PNG.

## Перший запуск

Перевірена конфігурація — Windows, Python 3.12, PyTorch 2.5.1 з CUDA 12.1, RTX 4080 Laptop. Команди виконуються з каталогу проєкту. Для створення нового середовища виберіть Python 3.12. У готовій локальній копії середовище вже є.

~~~powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu121
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m unittest -v
.\.venv\Scripts\python inpaint.py runs/pilot/best.pt panel.png mask.png restored.png
~~~

Для запуску на CPU додайте до останньої команди `--device cpu`. Обробляється прямокутник навколо маски з контекстом до 96 пікселів. Для маски на всю вертикальну стрічку потреба у відеопам’яті зростає з її площею.

## Архітектура

U-Net із 382 179 параметрами працює на трьох масштабах. Вхід містить видимі RGB-пікселі, маску і початкове заповнення, обчислене з видимого контексту. Згортки з розрідженням 1, 2 і 4 на найнижчій роздільності розширюють поле зору. Мережа вчиться коригувати початкове заповнення всередині маски. Функція втрат поєднує абсолютну похибку кольору та похибку горизонтальних і вертикальних різниць із вагою 0,25.

## Навчальні дані

Пілот спирається на `dataset.zip` та `val_dataset.zip` із локального проєкту Manhwa cleaner. Перший містить 75 сторінок, другий — 11. Імпортер читає YOLO-полігони й рамки, відбирає кольорові ділянки поза анотованими бульбашками, відкидає майже рівномірні заливки. Для кожного фрагмента формується прямокутна маска або маска зі штрихів. Ціллю є фрагмент до маскування. Розподіл між вибірками робиться за відбитком повної сторінки до нарізання. Відомостей для поділу за серіями в цих архівах бракує.

~~~powershell
.\.venv\Scripts\python prepare.py --out data/local --size 160 pages --train-zip 'C:\Projects\Manhwa cleaner\dataset.zip' --test-zip 'C:\Projects\Manhwa cleaner\val_dataset.zip' --per-page 18
.\.venv\Scripts\python train.py --data data/local --run runs/new-pilot --epochs 4 --batch 6 --device cuda
.\.venv\Scripts\python train.py --data data/local --run runs/new-pilot --epochs 8 --batch 6 --device cuda --resume
~~~

Для нового набору оберіть вільний каталог. Для продовження збереженого пілота використайте `--run runs/pilot --resume` із початковими batch, seed та learning rate. `last.pt` містить стан оптимізатора, `best.pt` — модель з найменшою валідаційною MAE. У робочій копії вже підготовлено `data/local`. Для відтворення з переносного архіву потрібні вихідні ZIP або відповідна підготовлена вибірка.

## Пари Hugging Face

Імпортер використовує ревізію `0868f943ac294af1b4ffcead8cdc1ec89ba4c4e2`. Він читає `input_image`, `output_image` і `mask_image`, перевіряє геометрію, бінаризує маски, відбирає кольорові панелі та формує фрагменти навколо напису. Параметр `--shards 1` завантажує першу з 50 частин. Повний набір займає близько 22,8 ГБ. Завершені частини зберігаються в `data/raw`. Можна також передати вже завантажені файли через `hf --parquet шлях1.parquet шлях2.parquet`. У картці набору умови ліцензії не наведено.

~~~powershell
.\.venv\Scripts\python prepare.py --out data/hf-pairs --size 160 hf --shards 1
.\.venv\Scripts\python train.py --data data/hf-pairs --run runs/hf-pilot --epochs 4 --batch 6
~~~

Джерело — [Webtoon Text Inpainting](https://huggingface.co/datasets/jhc90/webtoon_text_inpainting_data).

## Результат пілота

Модель пройшла 4 епохи з нуля на 1 026 фрагментах із 57 сторінок. Для вибору ваг використано 324 фрагменти з 18 інших сторінок. За валідаційною MAE обрана епоха 3. Базовий метод — багатомасштабне заповнення за доступними сусідніми пікселями. Метрики агрегуються за всіма RGB-значеннями всередині масок. Шкала MAE — від 0 до 1.

| Перевірка | Фрагменти | MAE моделі / базова ↓ | PSNR моделі / базовий ↑ |
|---|---:|---:|---:|
| Відкладений локальний архів, 11 сторінок | 198 | 0,07404 / 0,07534 | 17,30 / 17,27 дБ |
| Незалежна вибірка Hugging Face, 45 кольорових зображень | 135 | 0,09701 / 0,09854 | 15,33 / 15,36 дБ |

Із початку першого публічного Parquet отримано 50 цілих декодованих вхідних JPEG. Файли й контрольні суми збережені локально в `data/raw/hf-source-sample`. Решта першої частини та парні еталони залишаються для подальшого завантаження. Для зовнішньої перевірки на 45 кольорових зображеннях сформовано нові маски з відомою ціллю. Обидві перевірки вимірюють відновлення штучно прихованого малюнка. Окремий тест на справжніх корейських SFX потребує еталонних панелей із вимкненим шаром написів.

~~~powershell
.\.venv\Scripts\python evaluate_sample.py data/raw/hf-source-sample runs/pilot/best.pt runs/external
~~~

У `runs/external/comparison.png` наведено чотири приклади у порядку відбору. На великих масках навколо волосся та обличчя видно розмиття й втрату контурів. У `runs/pilot/metrics.json` є історія епох, у `runs/external/external.json` — координати зовнішніх фрагментів і відбиток ваг. У `tests.log` записано результати автоматичних тестів.
